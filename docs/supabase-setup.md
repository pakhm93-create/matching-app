# Supabase 연결하기 (한 번만 하면 됩니다)

Supabase는 **계정 로그인 + 데이터 저장소**를 무료로 빌려주는 서비스입니다.
지금까지 설문 답은 브라우저에만 저장돼서, 폰을 바꾸거나 기록을 지우면 사라졌습니다.
여기에 연결하면 답이 계정에 묶여 어디서 접속하든 남습니다.

**코드는 이미 다 준비돼 있습니다.** 아래 5단계만 하면 켜집니다.
연결하기 전까지는 앱이 예전처럼(브라우저 저장) 그대로 돌아가니 조급할 것 없습니다.

---

## 1. 계정 만들기

https://supabase.com 에 접속 → 오른쪽 위 **Start your project** → GitHub 계정으로 로그인.
(이미 깃허브가 있으니 그걸로 하면 제일 빠릅니다)

## 2. 프로젝트 만들기

**New project** 를 누르면 네 가지를 묻습니다.

| 칸 | 넣을 값 |
|---|---|
| Name | `matching-app` |
| Database Password | 아무 긴 문자열. **어딘가에 적어두세요.** 잃어버리면 재발급해야 합니다 |
| Region | **Northeast Asia (Seoul)** — 한국에서 쓰니 가장 가까운 곳 |
| Plan | Free |

만들어지는 데 1~2분 걸립니다.

## 3. 표(테이블) 만들기

왼쪽 메뉴에서 **SQL Editor** → **New query** 를 누릅니다.
이 저장소의 `supabase/schema.sql` 파일을 열어 **전체를 복사**해 붙여넣고 **Run**.

"Success. No rows returned" 이 나오면 성공입니다.
이 파일은 여러 번 실행해도 안전하게 만들어뒀습니다.

> 이 SQL이 하는 일: 프로필·설문 응답·좋아요·매칭·대화·토큰 표를 만들고,
> **남이 내 설문 응답을 못 읽도록 접근 권한을 잠급니다.**
> Supabase는 기본값이 "누구나 읽기 가능"이라 이 잠금이 꼭 필요합니다.

## 4. 주소와 키 가져오기

왼쪽 메뉴 **Project Settings**(톱니바퀴) → **API** 에 두 값이 있습니다.

- **Project URL** — `https://무언가.supabase.co`
- **anon public** 키 — 아주 긴 문자열

이 두 값을 아래 파일에 넣습니다. 프로젝트 폴더 맨 위에 **`.env.local`** 이라는
이름으로 새 파일을 만들고 (이름 앞의 점을 빼먹지 마세요):

```
NEXT_PUBLIC_SUPABASE_URL=여기에_Project_URL
NEXT_PUBLIC_SUPABASE_ANON_KEY=여기에_anon_public_키
```

> `anon` 키는 공개돼도 되는 키입니다. 위 3단계에서 건 접근 권한이 실제 방어선입니다.
> 반면 같은 화면의 **service_role** 키는 모든 잠금을 통과하는 열쇠라
> **절대 이 파일이나 코드에 넣으면 안 됩니다.**
> `.env.local`은 깃이 무시하도록 이미 설정돼 있어 깃허브에 올라가지 않습니다.

## 5. 로그인 링크가 돌아올 주소 알려주기

왼쪽 메뉴 **Authentication** → **URL Configuration**:

- **Site URL** 에 `https://matching-app-roan.vercel.app`
- **Redirect URLs** 에 `http://localhost:3000` 을 추가

메일로 받은 링크를 눌렀을 때 우리 앱으로 돌아오게 하는 설정입니다.
여기 없는 주소로는 돌려보내지 않습니다(가짜 사이트로 유인하는 걸 막는 장치).

---

## 마지막으로 — 배포된 앱에도 같은 값 넣기

내 컴퓨터의 `.env.local`은 내 컴퓨터에서만 쓰입니다.
Vercel에도 같은 값을 알려줘야 인터넷에 올라간 앱이 연결됩니다.

Vercel → **matching-app** 프로젝트 → **Settings** → **Environment Variables** 에서
위 두 줄을 이름/값으로 각각 추가한 뒤, **Deployments** 에서 맨 위 항목의
**⋯ → Redeploy** 를 누릅니다.

---

## 확인하는 법

```bash
npm run dev
```

설문을 끝까지 마치면 마지막에 **"답해주신 내용을 안전하게 보관할까요"** 화면이 뜹니다.
메일 주소를 넣고 → 받은 메일의 링크를 누르면 → 앱으로 돌아오면서 저장이 끝납니다.

Supabase의 **Table Editor → profiles / answers** 에 줄이 하나씩 생겼으면 성공입니다.

> 무료 요금제는 메일 발송이 시간당 몇 통으로 제한됩니다. 시제품 확인에는 충분하지만,
> 실제 사용자를 받을 때는 메일 발송 서비스를 따로 붙여야 합니다.
