# 설문 문항 설계

## 설계 원칙

1. **모든 답변은 숫자로 바꿀 수 있어야 한다.** 자유 서술은 매칭 계산에 못 쓴다
   → 객관식 또는 5점 척도만. 자유 서술은 프로필 소개글에만 허용
2. **중요도는 문항마다 묻지 않는다. 시작 전에 딱 한 번, 3개만 고른다.**
   문항마다 중요도를 물으면 응답 부담이 2배가 되어 이탈한다
3. **문항 수 60개 내외, 8~12분.** 더 길면 이탈한다
   진행률 바(◼◼◼◻◻)와 중간 저장 필수
4. **한 화면에 한 문항.** 넘기는 방식이 이탈률이 가장 낮다
5. **검사 이론을 사용자에게 노출하지 않는다.**
   성격 문항은 Big Five 기반이지만, 화면에는 그런 표현을 일절 쓰지 않는다.
   다른 문항들 사이에 자연스럽게 섞어 배치한다

## 응답 형식 3종

| 형식 | 설명 | 예시 |
|---|---|---|
| `scale` | 5점 척도 (1 전혀 아니다 ~ 5 매우 그렇다) | "처음 보는 사람과도 쉽게 대화한다" |
| `choice` | 객관식 단일 선택 | 종교, 음주 빈도 |
| `multi` | 복수 선택 | 관심사 태그 |

## 0단계 (설문 시작 전) — 절대 양보 못 하는 조건 TOP 3

설문 진입 전 한 화면. 아래에서 **정확히 3개**를 고르게 한다.

> 나이 · 지역 · 흡연 · 음주 · 종교 · 정치 성향 · 결혼 의향 ·
> 자녀 계획 · 직업군 · 키 · 학력 · 타투 · 반려동물

고른 3개는 각각 **원하는 범위**를 이어서 지정한다.
(예: `흡연` 선택 → "비흡연자만" / `나이` 선택 → "28~35세")

**이 3개가 하는 일**
- **하드 필터** — 조건에 안 맞으면 후보에서 아예 제외
- **가중치 5배** — 관련 문항의 유사도 비중을 크게 올림

나머지 조건들은 버려지지 않는다. **필터가 아닌 점수로** 반영된다.

> 화면 문구 예시:
> "가장 중요한 것 3가지만 골라주세요.
>  나머지도 매칭에 반영되지만, 이 3가지는 절대 조건으로 지켜드립니다."

## E. 성격 — 가중치 **중간 (0.15)**

> **화면에 "Big Five", "성격 검사" 같은 표현을 쓰지 않는다.**
> 다른 문항과 구분 없이 자연스럽게 섞어 배치한다.
> 내부적으로만 5개 축으로 집계한다.
>
> MBTI를 쓰지 않는 이유: 같은 사람이 재검사하면 유형이 자주 바뀌어
> 매칭 근거로 부적합. 축당 3문항, 역방향 문항을 섞어 성의 없는 응답을 걸러낸다.

| 내부 축 | 예시 문항 |
|---|---|
| 외향성 | "처음 보는 사람과도 쉽게 대화한다" |
| 친화성 | "다툼이 생기면 내가 먼저 양보하는 편이다" |
| 성실성 | "해야 할 일을 미루지 않는다" |
| 정서안정성 | "사소한 일에도 걱정이 많은 편이다" (역방향) |
| 개방성 | "가본 적 없는 곳을 여행하고 싶다" |

## F. 취향 — 가중치 **낮음 (0.10)**

관계 지속성 예측력은 낮지만, **매칭 성사 후 데이트 코스 추천의 재료**가 된다.
지금은 가중치를 낮게 두되 데이터는 충실히 모은다.
