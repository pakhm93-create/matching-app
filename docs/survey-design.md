# 설문 문항 설계

## 설계 원칙

1. **모든 답변은 숫자로 바꿀 수 있어야 한다.** 자유 서술은 매칭 계산에 못 씀
   → 객관식 또는 5점 척도만 사용 (자유 서술은 프로필 소개글에만 허용)
2. **문항마다 "나에게 얼마나 중요한지"를 따로 받는다.**
   같은 무신론자라도 어떤 사람은 상대 종교를 신경 안 쓰고, 어떤 사람은 절대 조건이다.
   이 중요도가 매칭 품질을 좌우하는 가장 중요한 장치다.
3. **문항 수는 60개 내외, 8~12분.** 더 길면 이탈한다.
   섹션을 나눠 진행률 바(◼◼◼◻◻)를 보여주고 중간 저장을 지원한다.
4. **한 화면에 한 문항.** MBTI 검사처럼 넘기는 방식이 이탈률이 가장 낮다.

## 응답 형식 3종

| 형식 | 설명 | 예시 |
|---|---|---|
| `scale` | 5점 척도 (1 전혀 아니다 ~ 5 매우 그렇다) | "처음 보는 사람과도 쉽게 대화한다" |
| `choice` | 객관식 단일 선택 | 종교, 음주 빈도 |
| `multi` | 복수 선택 (취미 등) | 관심사 태그 |

`scale`과 `choice`는 각각 **중요도(1 상관없음 ~ 4 매우 중요)**를 함께 받는다.

## B. 딜브레이커 — 후보를 아예 걸러내는 조건

사용자가 **"이건 절대 안 된다"**를 직접 지정한다. 여기 걸리면 유사도가 아무리 높아도 제외.

| 항목 | 내 상태 | 상대에게 허용 범위 |
|---|---|---|
| 흡연 | 비흡연 / 가끔 / 흡연 / 전자담배 | 복수 선택으로 허용 범위 지정 |
| 음주 | 안 함 / 가끔 / 자주 | 〃 |
| 나이 | (기본정보) | 최소~최대 범위 |
| 지역 | (기본정보) | 같은 시/도만 / 인접 포함 / 전국 |
| 결혼 의향 | 있음 / 없음 / 미정 | 〃 |
| 자녀 계획 | 원함 / 원치 않음 / 미정 | 〃 |
| 반려동물 | 키움 / 안 키움 / 알레르기 있음 | 〃 |
| 문신·타투 | 있음 / 없음 | 〃 |

## F. 성격 — 가중치 **중간**

MBTI 대신 **Big Five(5요인)** 사용. 이유: MBTI는 같은 사람이 다시 검사하면
결과가 자주 바뀌어 매칭 근거로 부적합. Big Five는 심리학계 표준.
**단, 사용자에게 보여줄 때는 MBTI처럼 친근한 유형 이름을 붙여 표시한다.**

각 축당 3문항 = 15문항. (역방향 문항 포함해 응답 성의 없음을 걸러냄)

| 축 | 의미 | 예시 문항 |
|---|---|---|
| 외향성 | 사람과 어울릴 때 에너지를 얻는가 | "처음 보는 사람과도 쉽게 대화한다" |
| 친화성 | 타인에게 협조적·배려적인가 | "다툼이 생기면 내가 먼저 양보하는 편이다" |
| 성실성 | 계획적이고 책임감 있는가 | "해야 할 일을 미루지 않는다" |
| 정서안정성 | 스트레스에 얼마나 흔들리는가 | "사소한 일에도 걱정이 많은 편이다" (역방향) |
| 개방성 | 새로운 경험·아이디어를 즐기는가 | "가본 적 없는 곳을 여행하고 싶다" |

대화 소재로는 좋지만 관계 지속성 예측력은 낮다. 가중치를 낮게 둔다.

| G2 | 좋아하는 영화 장르 | multi |
| G3 | 즐겨 듣는 음악 장르 | multi |

| G5 | 이상적인 주말 | choice: 집에서 휴식/카페·산책/액티비티/친구들과 모임/자기계발 |
